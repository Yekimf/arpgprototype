# Ashen Reliquary

A dark fantasy isometric browser ARPG with a starting town, procedural dungeons, three skill masteries, loot, identification, merchants, and item reforging.

## Download and play on a computer

1. [Download the game ZIP](https://github.com/Yekimf/arpgprototype/archive/refs/heads/main.zip).
2. Extract the ZIP.
3. Open `ashen-reliquary.html` in Chrome, Edge, Firefox, or Safari.

The single HTML file includes the code and painted artwork. It needs no installation or server on desktop. Mobile browsers can play it when it is served by a static website; some cannot run downloaded HTML directly.

Start in Emberfall and speak to Sister Maelin. Use WASD to move, hold left click to attack, 1–3 for abilities, Space to evade, Q to heal, K for masteries, I for inventory, E to interact, and T for a town portal. Touch controls appear on mobile.

Rescue Edrin by defeating the Hollow Warden to unlock free identification. Orrin buys and sells equipment; Garran repairs, salvages, and reforges it. Progress saves locally in the browser when storage is available.
